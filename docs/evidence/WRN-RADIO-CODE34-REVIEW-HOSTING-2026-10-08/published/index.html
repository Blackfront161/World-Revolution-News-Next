World Revolution News — user-initiated media playback

Android release 2.1.2, version code 34. This 35-second screen recording shows the isolated Android API 36 QA emulator. It is not a physical-device recording. The QA app uses the frozen release source and native media service; only the application ID differs for isolation.

Open or download the demonstration video (MP4)

  1. The user selects Radio CORAX and taps the visible Play button. The live stream connects and playback starts.
  2. The user leaves the app. The Android media card remains visible while playback continues.
  3. The user taps Pause and Play on the media card, then taps the station card to return to the app.
  4. The user taps Stop in the app. The player closes; the native test also verifies removal of the system media notification.

The video has no audio track. The accompanying native instrumentation test independently checks real audio-time advancement before backgrounding and after the system Play action. This demonstration covers live radio only.

The foreground service is used only for playback explicitly started by the user. Delaying or interrupting it delays or stops the selected audio. The app provides user-controlled Pause, Play and Stop. After a long pause, resuming requires visible app interaction; the app does not silently restart a destroyed player.
